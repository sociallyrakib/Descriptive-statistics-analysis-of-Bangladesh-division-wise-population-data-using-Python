# Bangladesh Division Population Analysis

A descriptive statistics analysis of Bangladesh's 8 administrative divisions using Python.

## What This Project Does
- Calculates mean, median, standard deviation
- Finds most and least populated divisions
- Uses real population data from Bangladesh Bureau of Statistics

## Key Findings (BBS Census 2022)
- Most populated: Dhaka (44.2 million)
- Least populated: Barisal (9.1 million)
- Mean population per division: 20.6 million
- High standard deviation (11.3 million) shows unequal population distribution

## Tools Used
- Python (no external libraries)

## Data Source
Bangladesh Bureau of Statistics (BBS), Population and Housing Census 2022
